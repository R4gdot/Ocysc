Status

This project is in very early development.
Current features:

- Basic calculator GUI
- Addition, subtraction, multiplication, and division
- Error handling
- Clear button
Known limitations:

- Limited functionality
- Basic user interface
- Features may change without notice
- Bugs are expected
About
OCYSC is a calculator project built in Python using Tkinter.
The long-term goal is to create a calculator that remains simple to use while allowing extensive customization through themes, settings, and configuration files.
Planned Features

- Improved UI
- Theme system
- JSON-based configuration
- Additional calculator functions
- Executable releases
